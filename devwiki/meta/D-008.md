# D-008 — A repaired observation needs a recurrence rule and visible evidence status

## Context

The v2 contracts choose an end-to-end episode as the first delivery's test of
the typed law. A page can conform while an observation lacks evidence; a
maintainer can repair that page, but the same omission can recur unless the
bundle declares and tests a rule. Evidence can later change without any page
changing (2026-09-26).

## Decision

`test/episode.test.ts` runs the sequence twice on a synthetic gardening bundle.
It starts with a conforming but ungrounded heat observation, repairs it through
`write`, and adds a section rule with a negative page, repaired twin and
positive page. `rule try` identifies the gap; `check` locates a recurrence;
the real pre-commit hook refuses that commit and accepts its repair. A later
commit changes the covered evidence, so `read` and `search` report the page
stale; re-pinning restores a fresh status. The two runs produce the same final
git tree, generated files and reported statuses.

## Consequences

- A passing rule test proves the rule behaves as declared on those pages. It
  does not prove the observation is true.
- The episode uses synthetic gardening material. Applying it to the owner's
  real vault is a separate owner-run step; this engine repository does not
  contain that vault's pages or evidence.
