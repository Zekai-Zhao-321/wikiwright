# Determinism of artifacts

## Mechanism

An artifact has one generator, and the generator is pure over the pages and
the registry: `generateArtifacts` sorts the pages by code-unit path and
derives every count and adjacency from one edge list
(`packages/core/src/generate/index.ts:62`, `:214-258`); the graph's nodes and
edges are sorted with `codeUnitCompare` (`:100`, `:165-171`) and serialized
by one function, two-space JSON with a trailing newline (`:24-30`). No edge
carries a line, so an edit above a section does not change the graph
(`:36-41`). The comparator is the only one permitted for an output-reaching
sort, and locale collation is banned in `packages/`
(`packages/core/src/identity/index.ts:28-32`); identity is NFD, full case
folding and NFC through one seam (`:19-26`), and paths are stored NFC by
the page walk so artifacts are byte-stable across filesystems
(`packages/cli/src/vaultfiles.ts:49-51`).

The same law reaches every derived byte. The kernel's SHA-256 is vendored,
integer arithmetic only, with `node:crypto` as an oracle in a test
(`packages/core/src/hash/index.ts:1-9`). Search computes its logarithm from a
series because `Math.log` is only implementation-approximated
(`packages/core/src/search/bm25.ts:16-29`) and classifies code points over
explicit ranges rather than `Intl`
(`packages/core/src/search/tokenize.ts:5-7`). The brief is rendered with no
clock and no absolute path (`packages/cli/src/brief.ts:224-228`), under a
header naming the law digest over the config and module bytes it was
rendered from (`:253`, `:337-344`); the
freshness report derives from origin state with no clock
(`packages/cli/src/freshness.ts:673`); the build stamp carries no timestamp
(`tools/write-build-info.ts:2-4`). A module that would break the property is
refused at its load, before it judges anything: the purity scan names the
clock, `Math.random`, `localeCompare`, `Intl`, `process.env`, `fetch`,
computed access to those globals and an import of any form by line, found
in the source as written or with its comments blanked
(`packages/core/src/modules/purity.ts:44-94`, `:155-263`, `:286-326`), and
the determinism fixture
judges the same bytes twice in one process and compares
(`packages/cli/src/modulefixture.ts:138-143`).

The property is checked rather than assumed. `check` compares the tree
against a fresh rebuild (`packages/cli/src/verbs/check.ts:98-115`); the gate
rebuilds from the index (`packages/cli/src/staged.ts:46-77`); artifacts land
through the shell's one staged replace — an exclusive temp beside each
target, renamed only once every artifact is written — so a failed run leaves
the old bytes (`packages/cli/src/artifacts.ts:50-58`;
`packages/cli/src/atomicwrite.ts:67-98`). The suite rebuilds every tracked
`generated/` from nothing and compares each byte — devwiki's, memory-synth's
and the two handbooks' (`packages/cli/test/generated-tracked.test.ts:1-7`,
`:30-35`), and the handbooks' rendered exports under `skills/` with them
(`:76-77`, `:94-101`); renders the same export in two directories and
compares the bytes (`packages/cli/test/export-copy.test.ts:340`; see
[[exports]]) — judges one fixture
through every state constructor under Bun and under Node
(`packages/cli/test/judge-property.test.ts:9-11`), and the release matrix
lints one corpus under both runtimes and diffs the envelopes
(`scripts/release-matrix.sh:65-77`).
