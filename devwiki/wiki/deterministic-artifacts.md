# Determinism of artifacts

## Mechanism

The law digest binds the engine document, loader-read law files, profile identities, dependencies and engine version. The content digest binds selected page paths and bytes plus source-path kind and membership, without reading raw source bytes. Generated artifacts are pure renders of that law and content.

Check renders the brief, graph, manifest, tag catalog and queue from its working-tree state. The brief uses composed type guidance, including inherited use_when and avoid_when. The gate compares tracked generated bytes from the index against the same render over staged law and pages.

The same law, page bytes and source-path existence facts produce the same artifacts regardless of checkout path, clock or locale. Each artifact has one generator; local or external Git HEAD observations stay out of generated bytes, and the queue excludes Git-derived freshness findings.

## Where it lives

Current source at this pin: `packages/core/src/digest/index.ts`, `packages/core/src/artifacts/index.ts`, `packages/cli/src/generated.ts`, `packages/cli/src/verbs/check.ts`.

Generated drift is an error with check --write as its fix. Fixed pages and generated artifacts are staged together before the first replacement; a staging failure changes neither. Replacements are complete per file, but a crash between generated files can leave a mixed set until the next run.
