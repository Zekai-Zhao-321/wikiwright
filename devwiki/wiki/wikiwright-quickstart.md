# wikiwright quickstart

## Setup

Bun is the toolchain; the built binary runs on Node 22.12 or later too.

```
bun install
```

## Run

```
bun run build
node packages/cli/dist/main.js help
node packages/cli/dist/main.js check --root devwiki
```

`devwiki` consumes the code kit, `packages/kit-code`, which `bun install`
links into `node_modules/` under `devwiki/` because both are workspace members
(`devwiki/package.json:5-8`). Installing the kit is the consent to run it: a
module runs inside the judge, and `check` loads the kit and proves it — its
purity scan and its determinism fixture — before it judges the bundle (see
[[loading-a-module]]).

Every command prints exactly one JSON envelope on stdout; exit code 5 means
the tool worked and the content failed its checks, exit 2 means the invocation
or the constitution is wrong.

## Verify

```
bun run check
```

`bun run check` is the gate: biome, the build, the test-project typecheck and
the whole suite under Bun. `bun run test:node` re-runs the suite under Node;
both runtimes are supported and generated bytes are identical across them.
The workflow `.github/workflows/check.yml` runs the gate and the node runner
on every push and pull request, on Linux and macOS; enable the gate locally
as the pre-commit hook with `git config core.hooksPath scripts/hooks`.
