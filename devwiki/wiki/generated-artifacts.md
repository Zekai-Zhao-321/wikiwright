# Generated artifacts

## Responsibilities

The five generated files are BRIEF.md, graph.json, manifest.json, tag-catalog.md and queue.md. The brief guides the three ways of working with a bundle and lists concrete types with inherited use and avoid guidance; the graph and manifest expose pages and links.

## Entry points

Current source at this pin: `packages/core/src/artifacts/index.ts`, `packages/cli/src/generated.ts`, `packages/cli/src/verbs/check.ts`.

## State

Check --write renders from the working tree; gate compares staged generated bytes when the index tracks them. The queue is a function of law, page bytes and source-path membership, with no Git-derived pin finding in it. Removing a raw source can invalidate an old queue without a Markdown edit.

## Invariants

The same input bytes generate identical outputs. Each file has one generator and must be staged beside the page or law change it describes.

## Failure modes

A hand edit is overwritten and a stale file is generated-drift. A linked, obstructed or unwritable generated destination is refused before writing. Check stages every changed artifact and any page fix before the first rename. Replacements are atomic per file, not a transaction over the set.
