# Start here

This handbook covers fruit trees and roses in a temperate garden, with cold
winters and mild, damp summers.

## How to use this handbook

Find the task in front of you and read its page from start to finish. Each page
names the climate it was written for; check that it matches your garden before
you follow it.

Note anything that did not work as written, and send it to the handbook's
maintainers rather than changing the page.
