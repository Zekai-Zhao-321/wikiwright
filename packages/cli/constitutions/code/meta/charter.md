# Charter

This bundle is the typed wiki of one codebase. It documents owned systems — not the
source tree — for contributors and agents working on the code. Pages carry registered
types with hard shapes; the source of truth for behavior is the code, and every claim
here should be checkable against it. Generated API listings, changelogs, and anything a
tool derives mechanically stay out; judgment about how the system works belongs in.
